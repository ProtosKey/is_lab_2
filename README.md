# Лабораторная работа №2

- Импорт городов, координат и губернаторов из JSON-файла через веб-интерфейс;
- Импорт выполняется одной транзакцией: при ошибке в любой записи не создаётся ни один объект;
- Валидация всех полей импорта по ограничениям предметной области;
- Вложенные объекты задаются в той же записи, что и город;
- История импорта: пользователь видит только свои операции, администратор все;
- Программные ограничения уникальности: координаты и имя губернатора проверяются в бизнес-логике приложения, без ограничений в БД;
- Права доступа: пользователь работает только со своими городами, губернаторами и координатами, администратор со всеми;
- Сценарии Apache JMeter для проверки изоляции транзакций при одновременной работе нескольких пользователей;

## Стек

- `Java 21`: язык бэкенда
- `Payara`: сервер приложений
- `Jakarta EE 10`: платформа
- `JAX-RS`: REST API
- `JSON-B`: разбор импортируемого файла
- `CDI-beans`: внедрение зависимостей и транзакции
- `JPA-EclipseLink`: ORM, отображение сущностей на таблицы
- `Bean Validation`: ограничения полей на уровне ORM
- `PostgreSQL`: хранение данных
- `Lombok`: генерация геттеров и сеттеров
- `Gradle`: сборка проекта
- `Apache JMeter`: нагрузочные сценарии и проверка уровней изоляции транзакций

## Структура

- `entity`: сущности базы данных;
- `model`: DTO: `*Dto` - ответы сервера, `*Request` - запросы форм, `*Ref` - ссылка на существующий объект либо инлайн-создание, `ImportBatchDto` - импортируемый файл;
- `mapper`: мапперы DTO и сущностей: по одному на каждый DTO, общий интерфейс `Mapper`;
- `repository`: запросы к базе данных;
- `service`: бизнес-логика и транзакции, включая импорт;
- `validator`: проверка входных данных, включая каждую запись импорта;
- `exception`: исключения приложения;
- `web`: REST-ресурсы;

## Запуск

Нужны Java 21, Docker и Payara, распакованный в папку `payara7/` в корне проекта.

```sh
docker-compose up -d
./gradlew build
./payara7/bin/asadmin start-domain
./payara7/bin/asadmin deploy --contextroot /is_lab_2 build/libs/city-system.war
```

Таблицы в базе создаются автоматически при первом деплое.
